# Contributing to Wolp Documentation

Thank you for helping improve the Wolp community documentation.

## How to contribute

You can contribute by:

* fixing incorrect information;
* improving existing guides;
* adding missing information;
* correcting spelling and formatting;
* suggesting new documentation.

## Pull requests

Before submitting a pull request, please make sure that:

1. The information is accurate.
2. The change is relevant to the Wolp community.
3. The documentation is easy to understand.
4. No private information or server credentials are included.

## Issues

If you find a problem with the documentation, you can open an issue describing the problem and, when possible, provide the correct information.
