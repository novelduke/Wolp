# Wolp

**Wolp** is a community-driven Minecraft SMP project focused on a vanilla-oriented survival experience and an active player community.

The project provides publicly available documentation, guides and community resources for players.

## Documentation

Our documentation contains information about:

* Getting started
* Server rules
* Gameplay features
* Frequently asked questions
* Voice chat
* Community guidelines
* Other useful information for players

## Community

Wolp is built around its community. Players can participate in discussions, suggest improvements and contribute to the project's public documentation.

## Contributing

We welcome community contributions to the documentation.

If you notice outdated or incorrect information, you can open an issue or submit a pull request.

## Project

Wolp is a private Minecraft SMP project with publicly available documentation and community resources.

This repository does not contain private server infrastructure, credentials or proprietary server configuration.
